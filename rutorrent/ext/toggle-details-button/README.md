### toggle_details_button plugin for ruTorrent

## Informations

- Adds a button to toggle details (next to "General" tab)

- Inspired by µTorrent interface

## Installation

Place all the plugin files in a directory called `toggle-details-button` in the rutorrent/plugins directory (Krate packages it under that name).

The plugin id used by `thePlugins.get(...)` is the folder name.
